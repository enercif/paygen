# paygen

PayPal.me-Link-Generator: Nutzername, Betrag und Währung eingeben, Link kopieren.

## Entwicklung

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

Der Build erzeugt eine einzelne, voll eigenständige `build/index.html` (JS, CSS und Fonts inline) — lässt sich per Doppelklick öffnen oder irgendwo statisch hosten.
